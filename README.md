# 🌟 ONG Esperança Viva - Portal Web

O **Portal Web da ONG Esperança Viva** é uma plataforma desenvolvida para apresentar as iniciativas da instituição, facilitar o cadastro de novos voluntários e divulgar canais de doação e apoio às causas sociais atendidas.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

* **HTML5:** Estruturação semântica das páginas web.
* **CSS3:** Estilização responsiva utilizando conceitos de Flexbox e CSS Grid.
* **JavaScript (ES6+):** Manipulação do DOM e validação dinâmica dos formulários.
* **Git & GitHub:** Controle de versão, gestão de tarefas e fluxo de trabalho colaborativo.

🌿 Práticas de Versionamento e Contribuição
O desenvolvimento do projeto segue boas práticas de engenharia de software para garantir rastreabilidade, padronização e organização no controle de versão.

1. Estrutura de Branches (GitFlow)
main: Ramificação contendo apenas código estável e testado em produção.

develop: Ramificação principal de integração para o desenvolvimento diário.

feature/*: Ramificações temporárias para criação de novas funcionalidades (ex.: feature/cadastro-voluntarios).

hotfix/*: Ramificações para correções urgentes diretamente aplicadas sobre a versão de produção.

2. Convenção de Commits (Conventional Commits)
As mensagens de commit seguem o padrão prefixado para legibilidade e automação do histórico:

feat: Adição de uma nova funcionalidade ao sistema.

fix: Correção de um bug ou comportamento inesperado.

docs: Alterações na documentação do projeto.

style: Ajustes de formatação, CSS ou layout sem alteração na lógica.

3. Versionamento Semântico (SemVer)
Os lançamentos do projeto seguem o padrão vMAJOR.MINOR.PATCH (ex.: v1.0.0):

MAJOR: Alterações incompatíveis ou grandes refatorações.

MINOR: Adição de funcionalidades mantendo a compatibilidade.

PATCH: Correções de bugs secundários e pequenos ajustes.
